# Pack: Research and analysis

## Intake questions

- The question, the decision it feeds, and how sure the answer must be.
- Scope: markets, period, competitors, sources to prefer or exclude.
- Output: short answer, table, or report. Depth.
- Internal data available? Exact files.

## Rules

- Only sources opened in this run count. Each claim: source, date of the source, date accessed. Model memory is a lead to check, not a source.
- Prefer primary sources (company, regulator, filing, paper). Mark secondary ones.
- Two independent sources for anything the decision rests on; if they disagree, show both.
- Separate finding, interpretation and recommendation. Say what was searched and not found.
- Paraphrase; quote sparingly and briefly.
- Data analysis: numbers come from a saved script and its output, kept in the run folder. State the row counts and filters.
- Scouts (light) collect and extract in parallel; one standard-tier synthesis; heavy only when sources conflict on the key point.

## Acceptance checks

Every claim has a working citation (Verifier opens a sample of at least five) · scripts re-run to the same numbers · limits and gaps stated.
